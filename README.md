# StyleFit — интернет-магазин одежды с подбором по типу фигуры

## О проекте

**StyleFit** — веб-приложение интернет-магазина одежды, предназначенное для удобного поиска и выбора товаров с учётом пола и типа фигуры пользователя.

Главная особенность проекта — возможность подобрать одежду в соответствии с выбранным типом фигуры. Также пользователи могут просматривать общий каталог, добавлять товары в корзину и оформлять заказы.

## Основные возможности

### Для пользователей
- Регистрация и авторизация.
- Просмотр и редактирование личного профиля.
- Просмотр каталога одежды.
- Фильтрация товаров по полу.
- Подбор одежды по типу фигуры.
- Просмотр карточек товаров.
- Добавление товаров в корзину.
- Оформление заказа с указанием данных доставки.

### Для администратора
- Управление товарами.
- Добавление и редактирование категорий.
- Управление типами фигуры.
- Добавление изображений товаров.
- Управление данными через административную панель Django.

## Запуск проекта через Docker

### 1. Клонирование репозитория

```bash
git clone https://github.com/fsubgh/StyleFit.git
```

### 2. Переход в папку проекта

```bash
cd StyleFit
```

### 3. Настройка переменных окружения

Создайте файл `backend/.env` и укажите необходимые переменные окружения, используемые в настройках Django.

Не публикуйте секретный ключ и другие конфиденциальные данные в открытом репозитории.

### 4. Сборка и запуск контейнера

```bash
docker compose up -d --build
```

### 5. Проверка состояния контейнера

```bash
docker compose ps
```

### 6. Открытие приложения

После запуска приложение доступно в браузере:

```text
http://localhost:8000
```

## Полезные команды Docker

Запуск проекта:

```bash
docker compose up -d
```

Остановка проекта:

```bash
docker compose down
```

Просмотр логов:

```bash
docker compose logs -f web
```

Перезапуск контейнера:

```bash
docker compose restart web
```

Пересборка проекта:

```bash
docker compose up -d --build
```

## Административная панель

Для управления содержимым приложения используется стандартная административная панель Django.

Адрес:

```text
http://localhost:8000/admin/
```

Для входа необходимо использовать учётную запись администратора Django.
